# 🛠️ AI-KU SKILLSET

AI-KU adalah asisten cerdas berbasis multi-agent dengan kapabilitas tingkat lanjut yang dioptimalkan untuk produktivitas profesional.

## 💻 Software Engineering & Development
- **Multi-File Context**: Memahami struktur seluruh direktori proyek (via `/ls`).
- **Code Forge**: Melakukan penulisan dan pengeditan kode langsung ke file sistem.
- **Security Audit**: Menganalisis kerentanan dalam kode (XSS, SQLi, Insecure Logic).
- **Refactoring**: Mengoptimalkan performa dan keterbacaan kode (Clean Code).
- **DevOps Support**: Membantu konfigurasi Docker, CI/CD, dan skrip otomasi.

## 🔍 Research & Information Retrieval
- **Deep Web Search**: Melakukan riset real-time dengan citasi sumber dan URL lengkap.
- **Autonomous Scout**: Mencari dan memperbarui pengetahuan secara mandiri di latar belakang.
- **Document Analysis**: Ekstraksi dan analisis mendalam dari file PDF dan TXT.
- **Source Validation**: Memverifikasi kebenaran informasi dari berbagai sumber terpercaya.

## 🧠 Logical Reasoning & Processing
- **ReAct Loop**: Penalaran otonom (Reason + Action) untuk menyelesaikan tugas kompleks dalam beberapa langkah.
- **Hazz Sandbox**: Eksekusi logika Python aman untuk perhitungan matematis presisi.
- **Oracle Reflection**: Proses berpikir internal mendalam sebelum memberikan jawaban akhir.
- **Interactive Clarification**: Bertanya balik (5-30 pertanyaan) untuk memastikan akurasi tugas.

## 🎨 Creative & Content Tools
- **Image Studio**: Generasi gambar AI (Flux) dengan dukungan berbagai style (Anime, Realistic, Art).
- **SEO Optimization**: Riset keyword dan penulisan konten yang dioptimalkan untuk mesin pencari.
- **Professional Writing**: Pembuatan dokumen teknis, email, dan konten sosial media yang natural.

## 🛡️ Reliability & Infrastructure
- **Low RAM Mastery**: Performa tinggi hanya dengan konsumsi RAM ~200MB.
- **Provider Fallback**: Redundansi sistem menggunakan 3+ provider AI untuk ketersediaan 99.9%.
- **Secure API**: Integrasi bot yang aman dengan X-API-KEY dan Rate Limiting.
- **Persistent Memory**: Memori jangka panjang terenkripsi dan terlindungi dari race condition.
